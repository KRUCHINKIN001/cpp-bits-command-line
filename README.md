# Вывод битов числа через аргументы командной строки (C++)

Консольная программа, которая принимает целое число через аргументы командной строки и выводит его двоичное представление (32 бита).

## Описание алгоритма

1. **Получение данных:** Программа считывает аргумент из командной строки (`argv[1]`).
2. **Валидация:** Строка аргумента преобразуется в тип `int` с помощью `std::stoi`. Обрабатываются исключения на случай, если введено не число или число слишком большое.
3. **Побитовый сдвиг:** В функции `printBits` запускается цикл от 31 до 0. 
   - На каждой итерации число сдвигается вправо на `i` позиций.
   - С помощью побитового И (`& 1`) извлекается текущий бит.
4. **Форматирование вывода:** Биты выводятся подряд. Каждые 8 бит добавляется пробел для удобства чтения (разделение на байты).

## Как запустить

Так как программа использует аргументы командной строки, запускать её нужно не из среды разработки (Code::Blocks), а из терминала (командной строки).
